# 月を歩く LRO版（Claude 改良版）

公開URL：https://yoshihiro-kitajima.github.io/lro-moon-explorer/claude/

もとの LRO 版（リポジトリ直下）のデータとライブラリ（three.js・標高・8K画像）を `../` から共有し、このフォルダには変更したプログラムと軽いデータだけを置いています。

## 追加した機能
- **すぐ表示**：最初に軽いデータ（標高 1440×720・約2MB、画像 2048×1024）で表示し、詳しいデータ（約40MB）は表示後に読み込んで切り替え。
- **断面図**：月面を2回クリックすると、2点間の標高グラフ（距離・最高・最低・高低差）を表示。
- **日付の太陽**：日付を入れると、その日の夜9時（日本時間）の太陽の向きで照らし、月齢を表示（誤差 1〜2°程度、秤動は含まない）。

軽いデータは `python prepare_lowres.py` で、親フォルダのデータから作り直せます。
